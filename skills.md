# skills — signal-system

*Per-repo agent guide for the OS-facts subscription contract between `system`
and `router`.*

## Checkpoint — read before editing

Before changing code in this repo, read this repo's `ARCHITECTURE.md` and the
consumer architecture files for `system/` and `router/` when the change affects
their contract use.

## What this repo is for

`signal-system` is the typed contract between the router (request side, opens
focus subscriptions) and `system` (reply/event side, emits focus observations on
a push stream). `schema/lib.schema` is the source of truth; `src/schema/lib.rs`
is generated by schema-rust and freshness-checked by `build.rs`.

Subscriptions follow Path A: open with `WatchFocus`, push typed events, close
with `UnwatchFocus` carrying `FocusSubscriptionToken`, and end with a
`SubscriptionRetracted` ack echoing the token. Sema classification words are not
request roots on this wire.

## What this repo owns

- `SystemTarget` (currently `NiriWindow`).
- The closed `SystemRequest` enum (`WatchFocus`, `UnwatchFocus`, `QueryFocus`,
  `QueryStatus`).
- The closed `SystemReply` enum, including `SubscriptionRetracted`.
- The closed `SystemEvent` enum on `FocusEventStream`.
- `SystemDaemonConfiguration`, encoded as a binary rkyv startup contract.
- Wire-form round-trip tests in `tests/` and canonical NOTA examples.

## Load-bearing invariants

- **Schema first.** Change `schema/lib.schema`, then refresh generated artifacts
  only with `SIGNAL_SYSTEM_UPDATE_SCHEMA_ARTIFACTS=1`.
- **Subscription close uses both sides.** Keep both `UnwatchFocus` and
  `SubscriptionRetracted`.
- **Wire enums are closed.** No `Unknown` variant.
- **No runtime code.** No Kameo, Tokio, socket, redb, or daemon glue in this
  crate.
- **Round trips cover every variant.** Update rkyv frame and NOTA witnesses when
  the contract changes.
